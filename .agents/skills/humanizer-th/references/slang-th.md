# คลังคำพูดคนไทย สแลง และระดับความไม่เป็นทางการ

ใช้เลือกคำให้ข้อความ "เป็นเสียงคน" ตามประเภทหน้า ไม่ใช่เพื่อโปรยสแลงให้เยอะ **สแลงที่ใส่ผิดที่เหมือน AI ที่พยายามเป็นวัยรุ่น** ซึ่งอ่านแล้วฝืนกว่าภาษาทางการเสียอีก

## 1. เปรียบเทียบระดับความไม่เป็นทางการ

| ระดับ | หน้าตา | ใช้กับ | ตัวอย่าง |
| --- | --- | --- | --- |
| 0 ทางการ | ไม่มีคำลงท้าย ไม่มีสแลง | กติกาที่ยกจากเอกสารจริง, ความปลอดภัย, ข้อกำหนดหลังบ้าน | "ห้ามบินเหนือบุคคลหรือแหล่งน้ำ" |
| 1 สุภาพกันเอง | "นะ", "เลย", "ก็", "แล้ว" พอประมาณ ไม่มีสแลง | บทเรียน /docs ส่วนอธิบายหลัก, ข้อความผิดพลาดในตัวจำลอง | "สั่งแล้วต้องรอให้โดรนทำเสร็จก่อนนะ" |
| 2 พี่คุยกับน้อง | คำลงท้ายเป็นธรรมชาติ สแลงเบาๆ 0–2 คำต่อหน้า | บทเรียนส่วน "พังตรงไหนบ่อย", หมายเหตุ, หน้า landing | "ลืม calibrate แล้วโดรนไหลเอาเรื่องเลย" |
| 3 เพื่อนคุยกัน | สแลงชัด อีโมจิได้ | 404, ข้อความว่าง, ข้อความขอบคุณ | "หน้านี้หายไปไหนไม่รู้ ลองกลับบ้านก่อนนะ" |

กฎ: **หนึ่งหน้าอยู่ระดับเดียว** ยกเว้นกล่อง "พังตรงไหนบ่อย" ที่ไหลลงมาหนึ่งระดับได้

## 2. คำลงท้ายและคำเสริมน้ำเสียง (ระดับ 1–3)

| คำ | หน้าที่ | ตัวอย่าง |
| --- | --- | --- |
| นะ | นุ่มลง ชวนให้ทำ | ใส่ delay ด้วยนะ |
| เลย | เน้น / ทันที | รอให้นิ่งเลย |
| แหละ | ยืนยัน สรุป | นี่แหละที่ทำให้โดรนไหล |
| น่ะ | อธิบายเพิ่ม | ปุ่มนี้น่ะ ใช้ลงจอดฉุกเฉิน |
| สิ / ซิ | ชวน / สั่งเบาๆ | ลองเปลี่ยนเป็น 100 สิ |
| ล่ะ | เปลี่ยนเรื่อง / เตือน | แล้วถ้าแบตหมดล่ะ |
| ไง | ย้ำสิ่งที่รู้อยู่ | ก็บินตรงๆ ไง |
| หรอก | ปฏิเสธเบาๆ | ไม่ยากหรอก |
| ก็ | ผ่อนน้ำเสียง | ก็ลองดูก่อน |
| แค่นี้เอง | ย้ำว่าง่าย | แค่นี้เอง |
| เดี๋ยว | เตือน / ค่อยทำ | เดี๋ยวโดรนตก |

ใช้ **นะ/เลย/แหละ** ได้บ่อยสุด ส่วน "ค่ะ/ครับ" ในเว็บนี้ **ไม่ใช้** เพราะผู้เขียนไม่ได้ระบุเพศหรือสถานะ ใช้ "นะ" แทน

| ราชการ/ทางการ | คนพูดจริง |
| --- | --- |
| ดำเนินการ / ทำการ | ทำ |
| ประสงค์ | อยาก |
| พิจารณา | ลองดู / คิดดู |
| ตรวจสอบ | เช็ก / ดู |
| ปรับเทียบ (ศัพท์โดรน ใช้ได้) | calibrate / ตั้งศูนย์ |
| ปฏิบัติ | ทำตาม |
| อาศัย | ใช้ |
| ภายใน 3 วินาที | ใน 3 วินาที |
| ประมาณการ | ประมาณ |

## 4. สแลงและคำพูดสบายๆ (เลือกใช้ทีละคำ)

ติดป้าย: **[ปลอดภัย]** ใช้ได้หลายช่วงอายุและไม่ล้าสมัยเร็ว · **[วัยรุ่น]** ใช้ได้แต่ต้องให้เข้ากับบริบท · **[หมดอายุเร็ว]** ติดยุค ไม่แนะนำในเว็บที่จะอยู่นาน

### ชม / ว้าว

| คำ | ความหมาย | ป้าย | ตัวอย่างในเว็บ |
| --- | --- | --- | --- |
| เจ๋ง | เก่ง น่าทึ่ง | ปลอดภัย | โดรนตัวนี้เจ๋งตรงที่… |
| เท่ | ดูดี | ปลอดภัย | ลงจอดแม่นแบบนี้เท่สุด |
| เทพ | เก่งมาก | วัยรุ่น | รุ่นพี่เทพมาก ลงจอดได้ที่เดิมเป๊ะ |
| เป๊ะ | ตรง แม่น | ปลอดภัย | ลงจอดเป๊ะกลางแท่น |
| เนี้ยบ | เรียบร้อย ละเอียด | ปลอดภัย | โค้ดเนี้ยบ อ่านง่าย |
| แจ่ม | ดี ลงตัว | ปลอดภัย | ได้ค่าแจ่มเลย |
| ว้าว | ตกใจในทางดี | ปลอดภัย | ว้าว! ลอยนิ่งจริง |
| ฟิน | ชอบ สุขใจ | วัยรุ่น | ฟินตอนโดรนลงแท่นพอดี |
| ปัง | ประสบความสำเร็จ ดูดี | วัยรุ่น / หมดอายุเร็วบ้าง | (ใช้ในหน้า landing ได้ไม่เกิน 1 ที่) |
| จึ้ง / เกินต้าน / ตึงๆ | ชมแบบวัยรุ่น | **หมดอายุเร็ว** | ไม่แนะนำ |

### พัง / ยาก / งง

| คำ | ความหมาย | ป้าย | ตัวอย่าง |
| --- | --- | --- | --- |
| งง | ไม่เข้าใจ | ปลอดภัย | ถ้ายังงงให้ลองใหม่ทีละบรรทัด |
| มึน | งงจนหัวตื้อ | ปลอดภัย | อย่าเพิ่งมึน ลองดูรูปก่อน |
| ตึง | เครียด / ยากเกินคาด | วัยรุ่น | ข้อนี้ตึงหน่อย ค่อยๆ ไป |
| ยาก / ซับซ้อน | | ปลอดภัย | |
| พัง / เจ๊ง | ใช้งานไม่ได้ | ปลอดภัย | ใบพัดบิ่นก็พังแล้ว |
| ร่วง / ตก | โดรนหล่น | ปลอดภัย | โดรนร่วงตอนแบตหมด |
| ทิ่ม / ปักหัว | โดรนพุ่งลงหัวคว่ำ | ปลอดภัย | ก้มเยอะไปโดรนจะปักหัว |
| ไหล | โดรนลอยไปเองจากตำแหน่งเดิม | ปลอดภัย | ลืม calibrate โดรนจะไหล |
| กระชาก | เคลื่อนแรงทันที | ปลอดภัย | ออกตัวแล้วกระชาก |
| แกว่ง / สั่น | โดรนไม่นิ่ง | ปลอดภัย | แบตอ่อนแล้วโดรนแกว่ง |
| รอด | ไม่พัง | ปลอดภัย | รอดมาได้เพราะเบรกทัน |
| หลุดคุม | บังคับไม่ได้ | ปลอดภัย | สัญญาณหายโดรนหลุดคุม |

| คำ | ความหมาย | ป้าย | ตัวอย่าง |
| --- | --- | --- | --- |

## 5. ศัพท์ในชมรม (ใช้ให้ตรงความหมายเดียวกันทั้งเว็บ)

| --- | --- | --- |

| ไหล | ลอยออกจากจุดโดยไม่ได้สั่ง | "ดริฟต์" (ใช้ครั้งแรกใส่วงเล็บได้) |

## 6. สิ่งที่ห้ามทำเสมอ

- ห้ามคำหยาบ คำด่า คำล้อเลียนรูปร่าง เพศ ภาษาถิ่น หรือกลุ่มคน
- ห้ามใช้สแลงในกติกา ความปลอดภัย ข้อกำหนด และข้อความเตือนที่ต้องไม่ตีความผิด
- ห้ามใช้สแลงเพียงเพื่อให้ "ดูเป็นคน" ถ้าไม่ได้ช่วยให้เข้าใจง่ายขึ้น ให้ใช้ภาษาธรรมดา
- ห้ามผสมสแลงยุคต่างกัน (เช่น "ปัง" กับ "ตึงๆ" กับ "เทพ" ในประโยคเดียวกัน)
- ห้ามเลียนสำเนียงหรือการสะกดเพี้ยน (เช่น "ค่าา", "เลยยย", "555") ในบทเรียนและหน้าหลัก ยกเว้นผู้ใช้สั่งเอง
- ห้ามใช้ภาษาตลกเกินเนื้อหา ถ้าอ่านแล้วรู้สึกว่ากำลังเล่นมุก ให้ตัดมุกออก

## 7. เทคนิคทำให้ประโยคเป็นเสียงคน

- ใส่ **สิ่งที่คนรู้สึกจริง** ตอนทำ ("ถ้าเห็นไฟฟ้านิ่ง อย่าเพิ่งขยับโดรนนะ")
- ใช้ **กริยาตรงๆ** แทนคำนามพอง ("ปรับเทียบก่อนบิน" ไม่ใช่ "การดำเนินการปรับเทียบก่อนปฏิบัติการบิน")
- ใช้ **ตัวเลขจริง** แทนคำว่ามาก/เยอะ ("ใช้เวลา 3 วินาที" ไม่ใช่ "ใช้เวลาพอสมควร")
- ใช้ **ของใกล้ตัว** เทียบ (เครื่องซักผ้า สายยาง เก้าอี้หมุน จักรยาน) แล้วต้องบอกว่าเทียบตรงไหน
- สลับ **ประโยคสั้นและยาว** อย่าให้ทุกประโยคยาวเท่ากัน
- อนุญาต **ความไม่แน่ใจที่จริง** ("ผู้ผลิตไม่ได้ระบุ ลองจับเวลาเอง") ดีกว่าความมั่นใจปลอม
