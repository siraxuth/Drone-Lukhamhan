## เช็กลิสต์ก่อนเริ่ม

- [ ] ตอบได้ว่าคนดูคือใคร และหลังดูจบควรทำอะไร (เข้าเว็บ? สแกน QR?)
- [ ] ทุกตัวเลขมีที่มาจริง จดคำสั่งที่นับไว้
- [ ] ภาพจริงที่ต้องใช้: หน้าเว็บ (capture), รูปผลงาน (ดึงจาก R2/หน้าเว็บ), โลโก้, ภาพสินค้า/อุปกรณ์
- [ ] ส่วนที่ต้องล็อกอินหรือข้อมูลส่วนตัว → วาดเป็นกราฟิกเอง ไม่ถ่ายของจริง
- [ ] ข้อความทุกฉากอ่านทันใน 2.5 วินาที
- [ ] วางแผนทั้ง 16:9 และ 9:16 พร้อมกัน
