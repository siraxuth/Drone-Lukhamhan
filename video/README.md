# คลิปแนะนำเว็บ (Remotion)

คลิป 60 วินาทีแนะนำ drone.dekgp.com สองขนาดจากฉากชุดเดียวกัน: `Intro16x9` (1920×1080) และ `Intro9x16` (1080×1920) · 30 fps · ไม่มีเสียงพากย์ ใช้ข้อความบนจอ เพลง และเสียงประกอบ

## คำสั่ง

```bash
bun install
bun run studio     # เปิด Remotion Studio ดู/แก้ทีละฉาก
bun run render     # out/intro-16x9.mp4 และ out/intro-9x16.mp4
```

เตรียมของ (ทำแล้ว ไฟล์อยู่ใน `public/` ทำซ้ำเมื่อหน้าเว็บเปลี่ยน):

```bash
bun run capture    # ถ่ายหน้า /docs และ /docs/lettering จาก localhost:3000 (หรือ bun scripts/capture.ts https://drone.dekgp.com)
bun run qr         # public/img/qr.svg ชี้ไป https://drone.dekgp.com
bun run audio      # สร้างเสียงประกอบและเพลงพื้นหลังด้วย python3 + numpy
```

## ฉาก (เวลาบนไทม์ไลน์รวม)

| ฉาก | เวลา | เรื่อง |
| --- | --- | --- |
| S1 | 0–4 วิ | ตัดภาพเร็ว 4 ช็อตตามจังหวะ แล้วเข้าคำถามเปิด + โดรนลอย |
| S2 | 4–8 วิ | โลโก้กระแทกเข้า พิมพ์ที่อยู่เว็บ ตัวเลขสรุป (68 หน้า · 5 สาย · 3 สนาม) |
| S3 | 8–16 วิ | หน้าเว็บเอียง 3 มิติ ชื่อบทวิ่งข้างหลัง ป้ายเด้งตามจังหวะ |
| S4 | 16–25 วิ | พิมพ์โค้ดแบบ `pArduino->` กดรัน กล้องซูม โดรนบินมีหาง คะแนนนับถึง 100 พลุแตก |
| S5 | 25–32 วิ | ผ่านด่านทีละอัน XP นับขึ้น ขึ้นอันดับ 1 |
| S6 | 32–39 วิ | การ์ดสนาม 3 ใบพลิกเข้า มีเส้นสแกน |
| S7 | 39–47 วิ | จุดแสง 300 จุด: กระจาย → หัวใจ → ดาว → คำว่า "ลือคำหาญ" + ภาพ Blender |
| S8 | 47–53 วิ | ตัดภาพผลงานเต็มจอตามจังหวะ แล้วรวบเป็นตาราง |
| S9 | 53–60 วิ | ชวนเข้าเว็บ ปุ่มเต้นตามจังหวะ QR มีวงหมุน |

ของเคลื่อนไหวที่ใช้ซ้ำอยู่ใน `src/ui/fx.tsx` (พื้นหลังเคลื่อนไหว, จังหวะเพลง `useBeat`, วงคลื่น, ตัวเลขนับ, marquee, พลุ) หัวเรื่องโผล่ทีละคำอยู่ใน `src/ui/Headline.tsx`
`bun run render` ปรับความดังเป็นราว -14 LUFS ด้วย `scripts/finish.sh` ให้อัตโนมัติ

ความยาวฉากและเสียงประกอบแก้ที่ `src/Intro.tsx` (`SCENES`, `SFX`) ข้อความแก้ในไฟล์ฉาก `src/scenes/*`
ขนาดตัวอักษรและระยะปลอดภัย (9:16 เว้นบน 220 ล่าง 380 ขวา 120 กันปุ่มของ TikTok/Reels) อยู่ที่ `src/layout.ts`

## เพลง

`public/audio/music.wav` เป็นเพลงสังเคราะห์จาก `scripts/make-audio.py` ไม่ติดลิขสิทธิ์ใคร อยากใช้เพลงอื่นให้วางไฟล์ชื่อเดิมทับ (ยาว 60 วินาทีขึ้นไป เพลงที่ใช้ซ้ำได้โดยไม่ติดลิขสิทธิ์)
