# คลิปแนะนำเว็บ (Remotion)

คลิป 60 วินาทีพาชมหน้าแรกเวอร์ชันปัจจุบันของ drone.dekgp.com ตั้งแต่ Hero เรื่องการทำงานของโดรน ฟีเจอร์ สนามแข่งขัน โดรนแปรอักษร ผลงาน ไปจนถึงท้ายหน้าเว็บ สองขนาดจากฉากชุดเดียวกัน: `Intro16x9` (1920×1080) และ `Intro9x16` (1080×1920) · 30 fps

## คำสั่ง

```bash
bun install
bun run studio     # เปิด Remotion Studio ดู/แก้ทีละฉาก
bun run render     # out/intro-16x9.mp4 และ out/intro-9x16.mp4
```

เตรียมของ (ทำแล้ว ไฟล์อยู่ใน `public/` ทำซ้ำเมื่อหน้าเว็บเปลี่ยน):

```bash
bun run capture    # จับหน้าแรกและหน้าจำลองจาก localhost:3000 (หรือ bun run capture https://drone.dekgp.com)
bun run qr         # public/img/qr.svg ชี้ไป https://drone.dekgp.com
bun run audio      # สร้างเสียงประกอบและเพลงพื้นหลังด้วย python3 + numpy
```

## ลำดับเรื่อง (เวลาบนไทม์ไลน์รวม)

| ฉาก | เวลา | เรื่อง |
| --- | --- | --- |
| S1 | 0–3 วิ | Landing page และโดรน 3 มิติ |
| S2 | 3–13 วิ | หลักการบิน 7 ช่วงจากหน้า Story |
| S3 | 13–20 วิ | บทเรียน โค้ด ตัวจำลอง สนาม และผลงาน |
| S4 | 20–27 วิ | สนามแข่งขันปัจจุบัน 3 ประเภท |
| S5 | 27–33 วิ | เรียนออกแบบโดรนแปรอักษร |
| S6 | 33–39 วิ | แกลเลอรีผลงานล่าสุด |
| S7 | 39–45 วิ | หน้าตัวจำลองและสนาม |
| S8 | 45–52 วิ | ลำดับเริ่มเรียน คนทำเว็บ และท้ายหน้า |
| S9 | 52–60 วิ | QR และชวนเริ่มเรียน |

ของเคลื่อนไหวที่ใช้ซ้ำอยู่ใน `src/ui/fx.tsx` (พื้นหลังเคลื่อนไหว, จังหวะเพลง `useBeat`, วงคลื่น, ตัวเลขนับ, marquee, พลุ) หัวเรื่องโผล่ทีละคำอยู่ใน `src/ui/Headline.tsx`
`bun run render` ปรับความดังเป็นราว -14 LUFS ด้วย `scripts/finish.sh` ให้อัตโนมัติ

ความยาวฉากและเสียงประกอบแก้ที่ `src/Intro.tsx` (`SCENES`, `SFX`) ข้อความแก้ในไฟล์ฉาก `src/scenes/*`
ขนาดตัวอักษรและระยะปลอดภัย (9:16 เว้นบน 220 ล่าง 380 ขวา 120 กันปุ่มของ TikTok/Reels) อยู่ที่ `src/layout.ts`

## เพลง

`public/audio/score.wav` เป็นดนตรีต้นฉบับที่สร้างด้วย `scripts/build-soundtrack.py` ใช้ร่วมกับเสียงประกอบแยกใน `src/Intro.tsx` บทพากย์ฉบับล่าสุดอยู่ที่ `VOICEOVER.md`; วางเสียง Pikiir ที่สร้างจากบทนั้นเป็น `public/audio/narration.mp3` ก่อน `bun run render` (มี `Preview16x9` และ `Preview9x16` สำหรับตรวจภาพก่อนใส่เสียงพากย์)
