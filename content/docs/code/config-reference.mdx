`config.hpp` คือกล่องรวมตัวเลขของโปรเจกต์ ความสูง เวลา มุม พัลส์เซอร์โว อยู่ที่นี่หมด หลักการคือ **แก้ที่เดียว ใช้ทุกที่** ไม่ต้องไล่แก้เลขดิบในทุกภารกิจ เหมือนป้ายราคาหน้าร้านอันเดียว ไม่ต้องไปแก้ราคาทุกกล่อง

<Callout type="warn" title="ยึดโค้ดเสมอ และวัดเอง">
ตารางนี้ยกจาก `config.hpp` ปัจจุบัน คู่มือของชมรมมีเลขบางตัวต่างออกไป (ระบุในคอลัมน์ท้าย) ให้เชื่อไฟล์โค้ด และวัดใหม่ทุกครั้งที่เปลี่ยนโดรน แบต หรือสนาม
</Callout>

## เซอร์โวและยิง

ค่าพัลส์ (µs) ส่งตรงให้เซอร์โว ค่ามุม (องศา) ใช้กับฟังก์ชันที่แปลงมุมเป็นพัลส์

| ชื่อ | ค่า | หน่วย | ความหมาย |
| --- | --- | --- | --- |
| `S_CLOSE` | 1500 | µs | ตำแหน่งกลาง/ปิด |
| `S_LEFT` | 1200 | µs | ปัดซ้าย |
| `S_RIGHT` | 2000 | µs | ปัดขวา |
| `S_CLOSE_ANGLE` | 88 | องศา | ตำแหน่งกลางแบบมุม |
| `S_LEFT_ANGLE` | 62 | องศา | ปัดซ้ายแบบมุม |
| `S_RIGHT_ANGLE` | 132 | องศา | ปัดขวาแบบมุม |
| `PRE_HOLD_MS` | 60 | ms | พักก่อนยิง |
| `FIRE_HOLD_MS` | 220 | ms | ค้างตำแหน่งยิง |
| `RESET_HOLD_MS` | 150 | ms | คืนตำแหน่งกลาง |
| `POST_DELAY_MS` | 60 | ms | พักหลังยิง |

พินยิงกำหนดไว้ตอนต้นไฟล์: `SHOOT1_PIN` = `PORT4`, `SHOOT2_PIN` = `PORT5` ซึ่ง `PORT4` คือขา D3 และ `PORT5` คือ A1 (นิยามใน `protocol.hpp`) ดู [servo-calibration](/docs/mechanisms/servo-calibration)

## วิธีแก้ค่าอย่างปลอดภัย

1. จดค่าเดิมไว้ หรือคอมเมนต์บรรทัดเดิมทิ้งไว้ใต้บรรทัดใหม่ (ชมรมทำแบบนี้กับ `16.39f`)
2. เปลี่ยนทีละค่า
3. อัปโหลด ทดสอบคำสั่งสั้นๆ ก่อน เช่น `drone.fw(100)`
4. จดผลลงตาราง

## ลองทำ

1. หาค่า `YAW_SETTLE_MS` ใน `config.hpp` แล้วคำนวณเวลานิ่งหลังจังหวะแรกของ `yaw_soft_stop` (ตอบ: 220 ms)
2. หาว่า `HEIGHT_GROUND` กับ `HEIGHT_FLIGHT` ใช้ในภารกิจไหนบ้าง (ใช้ค้นหาข้อความในโฟลเดอร์)
3. ลองเปลี่ยน `POKE_FAST_CM` แล้วสังเกตว่ามีไฟล์ไหนบ้างที่ได้รับผล

## พังตรงไหนบ่อย

- **แก้ตัวเลขดิบในภารกิจแทนที่จะแก้ config** ค่าเดียวกันกระจายหลายที่ สุดท้ายไม่ตรงกัน
- **ลืมต่อท้าย `f` ในค่าทศนิยม** `15.46` เป็น double ส่วน `15.46f` เป็น float โค้ดเดิมใช้ `f` ตลอด
- **เปลี่ยนเลขแต่ลืมอัปโหลดใหม่** โดรนยังใช้ค่าเดิม
- **เชื่อคู่มือมากกว่าไฟล์จริง** ดูคอลัมน์ "คู่มือเขียน" ในตาราง
