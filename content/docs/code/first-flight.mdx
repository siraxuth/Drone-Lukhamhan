## 1. เขียนทีละขั้น

โค้ดย่อมาจาก `KEY1_mode1()` ใน `Drone_Mission.ino` (ตัดส่วนที่ลองแล้วถูกคอมเมนต์ทิ้งออกให้อ่านง่าย)

<Steps>
<Step>

### 1. Calibrate: วางโดรนนิ่งๆ แล้วรอ

```cpp
drone.calibration();
delay(3000);
```

โดรนต้องตั้งศูนย์ไจโรบนพื้นที่นิ่ง ห้ามจับ ห้ามขยับ รอ 3 วินาทีให้เสร็จก่อนค่อยสั่งต่อ ถ้าอยากรวมสองบรรทัดเป็นบรรทัดเดียว ใช้ `drone.calibrateAndDelay(3000);`

</Step>
<Step>

### 2. Take off: ขึ้นบิน

```cpp
drone.takeOff();
delay(4000);
```

คำสั่งนี้แค่ส่งสัญญาณ "ขึ้น" แล้วจบทันที โดรนยังไม่ทันลอยถึงที่ จึงต้อง `delay` รอ ถ้าไม่รอ คำสั่งถัดไปจะซ้อนทับตอนโดรนกำลังขึ้น

</Step>
<Step>

### 3. ตั้งความสูง

```cpp
drone.sh(HEIGHT_TAKEOFF);   // 110 ซม. จาก config.hpp
```

`sh` ย่อมาจาก set height ส่งเป้าความสูงแล้วรอ 400 ms ให้โดรนไปถึง

</Step>
<Step>

### 4. เดินหน้า

```cpp
drone.fw(250);
```

ใช้เวลา 250 × 15.46 = 3865 ms แล้วเบรกอีก 400 ms (อ่านรายละเอียดที่ [distance-time](/docs/code/distance-time))

</Step>
<Step>

### 5. เลื่อนซ้าย

```cpp
drone.ml(255);
```

เลื่อนข้างโดยหัวโดรนยังหันไปทางเดิม ใช้เวลา 255 × 15.65 ≈ 3991 ms

</Step>
<Step>

### 6. ปล่อยบอล

```cpp
mission_drop_ch1_ch4();
```

ฟังก์ชันนี้เขียนเองใน `Drone_Mission.ino` เปิดช่อง 1 กับ 4 รอ 300 ms (`MISSION_DROP_WAIT_MS`) แล้วปิดประตู กลไกเซอร์โวอยู่ใน [ปล่อยสัมภาระ](/docs/mechanisms/payload-drop)

</Step>
<Step>

### 7. ลงจอด

```cpp
drone.autoLand();
```

โดรนลงเองจนถึงพื้น

</Step>
</Steps>

## 2. ประกอบเป็นฟังก์ชันเดียว

```cpp
void MyFirstMission() {
  drone.calibration();
  delay(3000);

  drone.takeOff();
  delay(4000);

  drone.sh(HEIGHT_TAKEOFF);
  drone.fw(250);
  drone.ml(255);

  mission_drop_ch1_ch4();
  drone.autoLand();
}
```

ผูกกับปุ่ม KEY11 ซึ่งโหมด Mission ยังไม่ได้ใช้ ใส่ในฟังก์ชัน `loopDroneMissionMode()`:

```cpp
drone.onKey11(MyFirstMission);
```

เวลารวมก่อนลงจอดประมาณ 3000 + 4000 + 400 + (3865 + 400) + (3991 + 400) + 400 ≈ **16.5 วินาที** จับเวลาดูว่าตรงไหม

</Callout>

## ลองทำ

1. ลดระยะเป็น `drone.fw(100)` และ `drone.ml(100)` บินก่อนเพื่อดูว่าไปตรงไหม
2. เพิ่ม `drone.bw(250)` ก่อน `autoLand()` ให้โดรนกลับมาลงที่เดิม
3. ลองสลับ ขั้น 2 กับ ขั้น 3 แล้วคิดว่าจะเกิดอะไรขึ้น (ตอบ: สั่งความสูงตอนยังอยู่บนพื้นไม่ได้ผล)

## พังตรงไหนบ่อย

- **โดรนไม่ขึ้น** ลืม calibrate หรือขยับโดรนระหว่าง calibrate
- **ขึ้นแล้วกระตุกหรือเอียง** `delay` หลัง `takeOff()` สั้นไป
- **ไปไม่ถึงจุดปล่อย** ค่า ms/cm ไม่ตรงกับโดรนตัวนั้น ให้วัดใหม่
- **กดปุ่มแล้วไม่เกิดอะไร** ลืมผูกด้วย `onKey11(...)` ใน loop หรือเลือกโหมดผิด ดู [เลือกโหมดบิน](/docs/code/modes)
