นักบินสายการบินเช็กลิสต์ก่อนบินทุกครั้ง แม้บินเส้นทางเดิมมาหมื่นเที่ยว เพราะความผิดพลาดที่ร้ายที่สุดมักเป็นเรื่องที่ "คิดว่าเช็กแล้ว" ทีมแข่งโดรนมีเวลา 150 วินาทีและโอกาสไม่กี่รอบ เช็กลิสต์ช่วยให้ไม่ต้องใช้ความจำ

## 1. ก่อนออกจากบ้าน

- [ ] ชั่งน้ำหนักโดรนพร้อมชุดปล่อยหรือชุดยิง (สเปก RCSA EDU 310 กรัม รวมแบตเตอรี่ ก่อนติดชุดกลไก) จดไว้ ตรวจกับเครื่องคิดเลขแรงยกใน [แรงที่ทำให้โดรนลอย](/docs/physics/forces)
- [ ] แบตเตอรี่ชาร์จเต็มทุกก้อน และมีสำรอง
- [ ] ใบพัดไม่แตกไม่งอ ใส่ทิศถูกตำแหน่ง
- [ ] เปิด `mode_config.hpp` ตรวจ `ACTIVE_FLIGHT_MODE` ว่าเป็นโหมดของประเภทที่จะแข่ง
- [ ] ตรวจว่าปุ่มรีโมทผูกกับท่าที่ตั้งใจ (ในโค้ดตอนนี้ KEY1 ของ Drone Mission เป็นเส้นทางทดสอบ ท่าเต็มอยู่ที่ KEY10)
- [ ] อัปโหลดโค้ดล่าสุด และเก็บสำเนาไฟล์ที่อัปโหลดไว้ในเครื่องที่สอง

## 2. ตรวจกลไกบนโต๊ะ (ถอดใบพัดก่อน)

- [ ] **ชุดปล่อยบอล** เปิดปิดแต่ละช่องผ่านโค้ดทดสอบ `release_the_ball()` ตรวจว่าปิดสนิท (ดู [ปล่อยสัมภาระ](/docs/mechanisms/payload-drop))
- [ ] บรรจุบอลไม่เกิน 20 ลูกต่อชุด เพราะเกินแล้วโดนหักลูกละ 1 คะแนน
- [ ] **ชุดยิง** เรียก `target_shooting()` ดูว่าซ้ายขวาออกครบ ก้านกลับ `S_CLOSE` ก่อนโดรนขยับ (ดู [ยิงลูกดอก](/docs/mechanisms/dart-shooting))
- [ ] **เข็ม** ปลายแหลมยาวไม่เกิน 1 มิลลิเมตร ตามกติกา
- [ ] เซอร์โวไม่ร้อน ไม่สั่น ไม่ดันชนขอบ

## 3. ที่สนาม ก่อนเริ่มแต่ละรอบ

- [ ] วางโดรนบนแท่น Takeoff ให้หัวหันไปทิศเหนือ ซึ่งเป็นทิศที่ `fw()` พุ่งไป
- [ ] พื้นเรียบ ไม่ขยับ **calibration** บนพื้นเรียบเสมอ ตัวจำลองเตือนทันทีถ้าข้าม
- [ ] ห่วงอยู่เหนือโดรน ความสูงลอดห่วงต้องอยู่ระหว่าง 20–120 ซม. จากพื้นสนาม ตัวอย่างในหน้านี้ใช้ `sh(100)`
- [ ] ตรวจลมและแสง ถ้ามีพัดลมใกล้ จดไว้ว่าระยะที่จูนอาจเพี้ยน
- [ ] ให้ทุกคนรู้บทบาท: คนกดปุ่ม คนจับเวลา คนดูโดรน ผู้ควบคุมทีมห้ามช่วยบังคับ
- [ ] ยืนยันกับกรรมการว่านับเวลาจากจุดไหน

## 4. ระหว่างบิน

- [ ] ไม่แตะรีโมทหลังกดเริ่ม ยกเว้นลงฉุกเฉิน กติกาให้ใช้วิทยุเฉพาะตอนเริ่มกับตอนลงฉุกเฉินเท่านั้น
- [ ] ถ้าโดรนเสียทิศ ตัดสินใจลงฉุกเฉินตั้งแต่เห็นผิด อย่ารอดูว่าจะดีขึ้น
- [ ] จดผลที่ได้จริง: ปล่อยกี่ลูกลงแท่น แตะกี่ลูกโป่ง ยิงถูกวงไหน

## 5. หลังบินแต่ละรอบ

- [ ] เปรียบผลจริงกับที่ตัวจำลองบอก ต่างตรงไหนให้จดทันที
- [ ] จดเวลารวม ถ้าเกิน 130 วินาทีให้ถือว่าอันตราย ตัดขั้นที่ได้คะแนนน้อยออก
- [ ] ตรวจน็อต ใบพัด สายเซอร์โว เปลี่ยนแบตก่อนรอบถัดไป
- [ ] ถ้าจูนตัวเลข ให้แก้ทีละค่า ทดสอบใหม่ แล้วจดค่าเก่าไว้

## ลองทำ

1. พิมพ์เช็กลิสต์ออกมา ลองให้เพื่อนทั้งทีมเช็กจริงกับโดรนที่ตั้งไว้ แล้วดูว่ามีข้อไหนที่ทุกคนตอบไม่ตรงกัน
2. จับเวลาการเตรียมโดรนก่อนบิน (calibration ถึงกดเริ่ม) ว่ากี่นาที เพราะเวลาระหว่างรอบสนามมีจำกัด
3. ซ้อมสถานการณ์ผิดพลาด: ให้เพื่อนแกล้งลืมข้อหนึ่ง แล้วดูว่ามีใครจับได้

## พังตรงไหนบ่อย

- **ข้าม calibration** เพราะ "เพิ่งทำเมื่อเช้า" โดรนขยับหรือถูกยกจะเสียศูนย์
- **อัปโหลดโค้ดผิดโหมด** ปุ่มกดแล้วโดรนรันท่าของประเภทอื่น
- **ซ้อมในห้อง แข่งในที่กลางแจ้ง** ลมทำให้ระยะต่างจากที่จูนไว้
- **ไม่ได้ทดสอบกลไกหลังเปลี่ยนแบต** น้ำหนักเปลี่ยนเล็กน้อยก็ส่งผลกับความสูง
- **เปลี่ยนโค้ดวันแข่ง** อย่าแก้ที่สนามโดยไม่มีเวลาทดสอบ ให้ใช้เวอร์ชันที่บินได้ล่าสุด
- **ไม่มีใครจดผล** รอบหน้าแก้ไม่ได้เพราะไม่รู้ว่าพลาดตรงไหน
