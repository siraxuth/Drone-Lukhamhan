## 1. ฟังก์ชัน

**ฟังก์ชัน (function)** คือชุดคำสั่งที่ตั้งชื่อไว้ เรียกชื่อเมื่อไรก็ทำงานชุดนั้น มีไว้ 3 อย่าง คือไม่ต้องเขียนซ้ำ แก้ที่เดียวแล้วถูกทุกที่ และให้ชื่อบอกว่ากำลังทำอะไร

ลองดูโค้ดที่ไม่มีฟังก์ชัน สมมติต้องแปลงองศาเป็นพัลส์ 3 ที่

```cpp
// ไม่ใช้ฟังก์ชัน: เขียนซ้ำ 3 รอบ ถ้าสูตรผิด ต้องแก้ 3 ที่
int a = map(constrain(30, 0, 180), 0, 180, 490, 2550);
int b = map(constrain(90, 0, 180), 0, 180, 490, 2550);
int c = map(constrain(150, 0, 180), 0, 180, 490, 2550);
```

```cpp
// ใช้ฟังก์ชัน: สูตรอยู่ที่เดียว อ่านง่ายกว่า
int a = servo_degree_to_pulse(30);
int b = servo_degree_to_pulse(90);
int c = servo_degree_to_pulse(150);
```

### เขียนฟังก์ชันเอง ทีละขั้น

<Steps>
<Step>

### เลือกชื่อที่บอกว่าทำอะไร

ใช้ชื่อที่อ่านแล้วรู้เรื่อง เช่น `servo_degree_to_pulse` (องศา → พัลส์) ไม่ใช่ `f1` หรือ `calc` ชื่อห้ามขึ้นต้นด้วยตัวเลข ห้ามมีช่องว่าง และตัวพิมพ์เล็กใหญ่ถือเป็นคนละชื่อ

</Step>
<Step>

### ตัดสินใจว่าจะคืนอะไร

ถามตัวเองว่า "ทำเสร็จแล้วอยากได้ผลลัพธ์กลับไปไหม" ถ้าได้ ให้ใส่ชนิดของผลลัพธ์หน้าชื่อ เช่น `int` ถ้าแค่สั่งให้ทำ ไม่ต้องคืนอะไร ใช้ `void`

</Step>
<Step>

### ระบุค่าที่ต้องรับเข้ามา

ในวงเล็บ เขียน "ชนิด ชื่อ" ของแต่ละค่า คั่นด้วยจุลภาค เช่น `(int angle)` ถ้าไม่ต้องรับอะไรเลย ปล่อยวงเล็บว่าง

</Step>
<Step>

### เขียนตัวฟังก์ชันในปีกกา แล้ว return

ใส่คำสั่งข้างใน `{ }` ถ้ามีชนิดที่คืน ต้องจบด้วย `return ค่า;` ทุกเส้นทางที่โค้ดไปถึง

</Step>
</Steps>

ผลลัพธ์คือฟังก์ชันจริงจาก `Servo_Degree.ino`

```cpp
// Servo_Degree.ino
int servo_degree_to_pulse(int angle) {
  angle = constrain(angle, SERVO_DEGREE_MIN, SERVO_DEGREE_MAX);
  return map(angle, SERVO_DEGREE_MIN, SERVO_DEGREE_MAX,
             SERVO_DEGREE_MIN_PULSE, SERVO_DEGREE_MAX_PULSE);
}
```

- `int` หน้าชื่อ คือ **ชนิดที่คืนกลับ** (return type)
- `servo_degree_to_pulse` คือชื่อ
- `(int angle)` คือ **พารามิเตอร์** ค่าที่รับเข้ามา
- `return` ส่งผลกลับไปที่ผู้เรียก และจบฟังก์ชันทันที

### ไล่การทำงานทีละขั้น

โค้ดเรียก `servo_degree_to_pulse(200)` ทำงานตามนี้ (ค่าคงที่ใน `Servo_Degree.ino`: 0–180 องศา, พัลส์ 490–2550)

<Figure caption="เรียกด้วย 200 องศา ซึ่งเกินช่วง: constrain ตัดเหลือ 180 แล้ว map แปลงเป็น 2550">
  <CallTrace />
</Figure>

ถ้าไม่มี `constrain` ตัวเลข 200 จะผ่าน `map` ตรงๆ ได้ 2778 ซึ่งเกินช่วงที่เซอร์โวรับได้ (สูงสุด 2550) `constrain` จึงเป็นด่านกันค่าหลุด

### `constrain` คืออะไร

`constrain(x, low, high)` บังคับให้ `x` อยู่ในช่วง `low` ถึง `high`

| เรียก | ผลลัพธ์ | เหตุผล |
|---|---|---|
| `constrain(90, 0, 180)` | 90 | อยู่ในช่วง ไม่แตะ |
| `constrain(200, 0, 180)` | 180 | เกินสูงสุด ถูกลดเหลือ 180 |
| `constrain(-20, 0, 180)` | 0 | ต่ำกว่าต่ำสุด ถูกยกเป็น 0 |

## 2. `map()` คืออะไร

### คืออะไร

`map` คือฟังก์ชันที่ Arduino มีให้อยู่แล้ว ทำหน้าที่ **แปลงตัวเลขจากไม้บรรทัดอันหนึ่งไปอีกอัน** โดยรักษาสัดส่วนเดิม เหมือนแปลงเปอร์เซ็นต์เป็นคะแนน ได้ 50% จาก 0–100 ก็เท่ากับ 5 คะแนนจาก 0–10

```cpp
map(ค่า, จากต่ำ, จากสูง, ไปต่ำ, ไปสูง)
```

### ใช้เพื่ออะไร ใช้ตอนไหน

ใช้เมื่อ "หน่วยหรือช่วงของตัวเลขที่เรามี" ไม่ตรงกับ "ที่ฮาร์ดแวร์ต้องการ" ในงานโดรนเจอบ่อย 3 แบบ

- **องศา → พัลส์เซอร์โว** เราคิดเป็นองศา (0–180) แต่เซอร์โวต้องการความกว้างพัลส์ (490–2550 µs) นี่คือตัวอย่างในโค้ดชมรม
- **ค่าเซนเซอร์ → ค่าที่ใช้งานได้** เช่น ขา analog อ่านได้ 0–1023 แต่ต้องการ 0–255
- **ค่าสเกลหนึ่ง → อีกสเกล** เช่น ความเร็ว 0–100% เป็นค่า 1–7 ที่คำสั่งโดรนรับ

### ทำงานยังไง

<Figure caption="องศาบนไม้บรรทัดบนเทียบกับพัลส์บนไม้บรรทัดล่าง ตำแหน่งสัดส่วนเท่ากัน 90° อยู่กลาง ได้ 1520 µs 45° อยู่ 1 ใน 4 ได้ 1005 µs">
  <MapScale />
</Figure>

สูตรที่อยู่เบื้องหลัง

```text
ผลลัพธ์ = (ค่า − จากต่ำ) × (ไปสูง − ไปต่ำ) ÷ (จากสูง − จากต่ำ) + ไปต่ำ
```

แทนค่า `map(90, 0, 180, 490, 2550)` ทีละบรรทัด

<Steps>
<Step>

### หาว่าค่าอยู่ตรงไหนของไม้บรรทัดเดิม

`90 − 0 = 90` ส่วนความยาวของไม้บรรทัดเดิมคือ `180 − 0 = 180` แปลว่าอยู่ที่ครึ่งทาง (90 ÷ 180 = 0.5)

</Step>
<Step>

### เอาสัดส่วนนั้นไปคูณความยาวของไม้บรรทัดใหม่

ความยาวใหม่คือ `2550 − 490 = 2060` ครึ่งหนึ่งของ 2060 คือ `1030`

</Step>
<Step>

### บวกจุดเริ่มของไม้บรรทัดใหม่

`1030 + 490 = 1520` ได้ผลลัพธ์ 1520

</Step>
</Steps>

### ข้อควรระวัง 3 ข้อ

1. **`map` ไม่ตัดค่าให้อยู่ในช่วง** ถ้าใส่ค่านอกช่วงเดิม ผลลัพธ์ก็หลุดช่วงใหม่ด้วย (เช่น `map(200, 0,180, 490,2550)` ได้ 2778) จึงต้องใช้คู่กับ `constrain` เหมือนในโค้ดชมรม
2. **คำนวณด้วยจำนวนเต็ม ทศนิยมถูกตัดทิ้ง** `map(1, 0, 3, 0, 10)` ได้ 3 (ไม่ใช่ 3.33) ถ้าต้องการทศนิยม ให้คำนวณสูตรเองด้วย `float`
3. **ใส่ช่วงกลับด้านได้** `map(x, 0, 100, 100, 0)` กลับทิศ ค่า 0 กลายเป็น 100

```cpp
// ตัวอย่างที่คอมไพล์ได้: ค่าจากขา analog 0-1023 เป็น 0-255
int v = analogRead(A0);
int level = map(v, 0, 1023, 0, 255);
```

## 3. ค่าที่ส่งเข้าฟังก์ชัน

### ส่งเข้าไปคือ "คัดลอก"

เมื่อเรียก `half(a)` ค่าของ `a` ถูกคัดลอกให้พารามิเตอร์ ฟังก์ชันแก้ของตัวเองได้โดยของเดิมไม่เปลี่ยน

<Figure caption="x ในฟังก์ชันเป็นสำเนา แก้เป็น 150 แต่ a ข้างนอกยังเป็น 300">
  <ParamCopy />
</Figure>

```cpp
int half(int x) {
  x = x / 2;       // แก้สำเนา
  return x;
}

void setup() {
  Serial.begin(9600);
  int a = 300;
  Serial.println(half(a));   // 150
  Serial.println(a);         // 300 ไม่เปลี่ยน
}
void loop() {}
```

### หลายพารามิเตอร์ และตัวอย่างจากโค้ดชมรม

ฟังก์ชันรับได้หลายค่า คั่นด้วยจุลภาค ตัวอย่างจริงจาก `protocol.cpp`: บินหน้า X เซนติเมตร คือเปิดมอเตอร์แล้วรอ "ระยะ × เวลาต่อซม."

```cpp
// แนวคิดเดียวกับ move_forward_cm ใน protocol.cpp
unsigned long cm_to_ms(int cm, float ms_per_cm) {
  return (unsigned long)(cm * ms_per_cm + 0.5f);   // +0.5 เพื่อปัดเศษ
}
```

เรียก `cm_to_ms(100, 15.46f)` ได้ 1546 ms เรียก `cm_to_ms(352, 15.46f)` ได้ 5442 ms (352 × 15.46 = 5441.92 ปัดเป็น 5442) ฟังก์ชันจริงในโค้ดคือ `ms_round(distance_cm * MS_PER_CM_FWD)` ใน `config.hpp`

### ตัวแปรข้างในฟังก์ชัน (local) มองไม่เห็นข้างนอก

```cpp
int add_one(int x) {
  int result = x + 1;    // result เกิดและตายในฟังก์ชันนี้
  return result;
}

void setup() {
  add_one(5);
  // Serial.println(result);   // error: 'result' was not declared
}
```

ตัวแปรที่ประกาศนอกฟังก์ชันทุกตัว (global) เช่น `forwardDistanceCM` ทุกฟังก์ชันมองเห็น แต่ยิ่งมี global มาก ยิ่งหาจุดที่แก้ค่ายาก ใช้เท่าที่จำเป็น

### อยากให้ฟังก์ชันแก้ตัวแปรเดิม: ใช้ `&`

ใส่ `&` หลังชนิด ฟังก์ชันจะได้ตัวแปรตัวจริง ไม่ใช่สำเนา

```cpp
void double_it(int &x) {
  x = x * 2;
}

void setup() {
  Serial.begin(9600);
  int a = 300;
  double_it(a);
  Serial.println(a);   // 600
}
void loop() {}
```

## 4. ฟังก์ชันที่ไม่คืนค่า และค่าเริ่มต้น

### void: ไม่คืนค่า

ถ้าฟังก์ชันทำงานเฉยๆ ไม่มีผลลัพธ์ ใช้ `void`

```cpp
// config.hpp
static inline void hold_now(uint16_t ms = 250){
  pArduino->set_direction(7,2);
  delay(ms);
}
```

### ค่าเริ่มต้น (default argument)

`uint16_t ms = 250` แปลว่าถ้าไม่ใส่ค่า ให้ใช้ 250

```cpp
hold_now();      // รอ 250 ms
hold_now(400);   // รอ 400 ms
```

คลาส `Arduino` ใช้เทคนิคนี้ทุกที่ ดู `protocol.hpp`

```cpp
void move_forward_cm(uint16_t distance_cm, uint8_t speed = 2);
```

`move_forward_cm(100)` = บินหน้า 100 cm ที่ความเร็ว 2 ส่วน `move_forward_cm(100, 4)` = ความเร็ว 4 พารามิเตอร์ที่มีค่าเริ่มต้นต้องอยู่ **ท้ายสุด** เท่านั้น

### `static inline` คืออะไร

เจอบ่อยหน้าฟังก์ชันใน `config.hpp` จำสั้นๆ ว่า `static` = ใช้ได้เฉพาะในไฟล์นี้ `inline` = ขอให้คอมไพเลอร์แปะโค้ดลงตรงที่เรียกเลย ไฟล์ `.hpp` ที่ถูก include หลายที่ควรใส่สองคำนี้ เพื่อไม่ให้เจอ error นิยามซ้ำ

### ประกาศไว้ก่อน (prototype)

C++ อ่านจากบนลงล่าง เรียกฟังก์ชันที่ยังไม่เคยเห็นชื่อ จะ error บอกให้ประกาศหัวไว้ก่อน

```cpp
int half(int x);          // ประกาศ (ยังไม่มีตัวฟังก์ชัน)

void setup() {
  Serial.begin(9600);
  Serial.println(half(300));
}
void loop() {}

int half(int x) {         // นิยามไว้ทีหลังได้
  return x / 2;
}
```

ไฟล์ `.ino` ไม่ต้องทำเอง Arduino IDE สร้างประกาศให้อัตโนมัติ แต่ไฟล์ `.cpp` ต้องเขียนเอง ซึ่งนั่นคือหน้าที่ของไฟล์ `.hpp`

## 5. ส่งฟังก์ชันไปให้ฟังก์ชันอื่น

ฟังก์ชันก็ส่งต่อได้ ส่ง "ชื่อฟังก์ชัน" ไม่ใส่วงเล็บ ไปให้อีกฟังก์ชันถือไว้เรียกทีหลัง นี่คือวิธีผูกปุ่มรีโมทของชมรม

```cpp
// DroneEasy.hpp
```

## 6. อาร์เรย์

```cpp
// Drone_Mission.ino
int forwardDistanceCM[4] = { 352, 352, 352, 352 };
int backwardDistanceCM[4] = { 252, 252, 252, 252 };
```

`int scores[4];` ได้ 4 ช่อง ช่องละ `int` ยังไม่ได้ใส่ค่า (ค่ามั่ว) ขนาดต้องเป็นตัวเลขตายตัว

</Step>
<Step>

```cpp
int a = scores[0];    // 10 ช่องแรก
```

</Step>

### วนทุกช่องด้วย for

### วนทุกช่องด้วย for

ตัวอย่างบวกทุกช่อง (ทดสอบคอมไพล์สำหรับ Nano แล้ว)

```cpp
int forwardDistanceCM[4] = { 352, 352, 352, 352 };

int total() {
  int sum = 0;
  for (int i = 0; i < 4; i++) {
    sum += forwardDistanceCM[i];
  }
  return sum;
}

void setup() {
  Serial.begin(9600);
  Serial.println(total());   // 1408
}

void loop() {}
```

ใช้ `i < 4` ไม่ใช่ `i <= 4` เพราะช่องสุดท้ายคือ `[3]`

### หาจำนวนช่องโดยไม่ต้องนับเอง

ถ้าวันหนึ่งเพิ่มเป็น 5 ช่อง แล้วลืมแก้เลข 4 ในลูป จะอ่านขาด ใช้ `sizeof` ให้โปรแกรมนับให้

```cpp
int n = sizeof(forwardDistanceCM) / sizeof(forwardDistanceCM[0]);   // 4
```

`sizeof(อาร์เรย์)` คือจำนวนไบต์ทั้งก้อน (4 ช่อง × 2 ไบต์ = 8 บน Nano) หารด้วยขนาดช่องเดียว (2 ไบต์) ได้จำนวนช่อง 4 วิธีนี้ใช้ได้เฉพาะในที่ที่ประกาศอาร์เรย์ ภายในฟังก์ชันที่รับอาร์เรย์มา ใช้ไม่ได้ (ดูข้อถัดไป)

### ส่งอาร์เรย์เข้าฟังก์ชัน

ฟังก์ชันที่รับอาร์เรย์ ไม่รู้ว่ามีกี่ช่อง ต้องส่งจำนวนไปด้วยเสมอ และฟังก์ชันได้ตัวจริง ไม่ใช่สำเนา (แก้ข้างในแล้วข้างนอกเปลี่ยน)

```cpp
long sum_of(const int arr[], int n) {
  long s = 0;
  for (int i = 0; i < n; i++) s += arr[i];
  return s;
}

int forwardDistanceCM[4] = { 352, 352, 352, 352 };

void setup() {
  Serial.begin(9600);
  Serial.println(sum_of(forwardDistanceCM, 4));   // 1408
}
void loop() {}
```

`const` หน้า `int arr[]` สัญญาว่าฟังก์ชันนี้ "อ่านอย่างเดียว ไม่แก้" ช่วยกันพลาดแก้ค่าโดยไม่ตั้งใจ

### ในโค้ดชมรม

ไฟล์ `Drone_Mission.ino` ประกาศ `forwardDistanceCM[4]` และ `backwardDistanceCM[4]` ไว้ที่หัวไฟล์เป็น "ค่าปรับภารกิจ" รวมจุดเดียว ถ้าวันแข่งต้องปรับระยะ เปิดมาแก้บรรทัดบนสุดที่เดียว ไฟล์ยังมีตัวนับรอบ `k2_round` และ `payload_round10` ที่ใช้แยกว่ารอบนี้เป็นรอบแรกหรือรอบสอง (ข้อสังเกต: ในไฟล์เวอร์ชันนี้ อาร์เรย์สองตัวข้างบนยังไม่ถูกอ้างด้วยเลขลำดับที่ใดเลย ระยะบินจริงในฟังก์ชันภารกิจใส่เป็นตัวเลขตรงๆ ถ้าจะใช้ต้องเพิ่มโค้ดเรียก `forwardDistanceCM[รอบ]` เอง)

## พังตรงไหนบ่อย

- **เลขลำดับเกิน** `forwardDistanceCM[4]` อ่านนอกอาร์เรย์ ได้ค่ามั่ว ไม่มี error ให้
- **ลืม `return`** ฟังก์ชันที่ต้องคืนค่า คอมไพล์ผ่านแต่ผลที่ได้เป็นค่าสุ่ม
- **ลืมว่า `map` ไม่ตัดค่า** ใส่องศาเกินช่วงแล้วเซอร์โวถูกสั่งเกินสุด ให้ครอบด้วย `constrain` เสมอ
- **หารจำนวนเต็มแล้วเศษหาย** `1 / 2` ได้ 0 ไม่ใช่ 0.5 ถ้าต้องการทศนิยมให้ใช้ `1.0f / 2`
- **ใส่วงเล็บตอนส่งฟังก์ชันไปผูกปุ่ม** เรียกทันทีแทนที่จะรอปุ่ม
- **ประกาศฟังก์ชันหลังใช้** Arduino IDE จัดการให้ในไฟล์ `.ino` แต่ใน `.cpp` ต้องเขียนประกาศไว้ก่อน
- **ชื่อฟังก์ชันซ้ำข้ามไฟล์ `.ino`** ดู [โครงสร้างโปรเจกต์](/docs/arduino/project-structure)
