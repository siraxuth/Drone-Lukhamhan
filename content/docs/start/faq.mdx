## ก่อนเริ่ม

**ไม่มีพื้นฐานเลย เรียนได้ไหม?**
ได้ เริ่มจาก [โดรนบินได้ยังไง](/docs/start/how-a-drone-flies) แล้วอ่านเรียงตามเมนู บท C++ เขียนตั้งแต่ตัวแปรตัวแรกและอธิบายคำสั่งทีละบรรทัด

**ต้องมีโดรนจริงไหม?**
ไม่จำเป็นในช่วงแรก [ตัวจำลองการบิน](/simulator) ใช้สนาม 10×10 เมตรและค่าเวลาจริงของโดรน ลองเขียนคำสั่งแล้วดูคะแนนก่อน แต่ก่อนแข่งต้องบินจริงเพื่อวัดค่าของเครื่องตัวเอง

**ต้องรู้คณิตศาสตร์แค่ไหน?**
บวก ลบ คูณ หาร และตรีโกณมิติพื้นฐาน (sin, cos, tan) ในบทฟิสิกส์ ทุกสูตรมีตัวอย่างที่แทนตัวเลขให้ดู

**ใช้ระบบอะไรเขียนโค้ด?**
Arduino IDE ใช้ได้ทั้ง Windows, macOS, Linux ขั้นตอนอยู่ที่ [ติดตั้ง Arduino IDE](/docs/arduino/install-ide)

## เรื่องโค้ด

**ทำไมโดรนไม่ไปถึงจุดที่สั่ง ทั้งที่โค้ดถูก?**
`fw(250)` ไม่ได้บอกให้ไปให้ถึง 250 ซม. แต่คือบินไปข้างหน้า "ตามเวลาที่คำนวณว่าเท่ากับ 250 ซม." แล้วหยุด ถ้าค่า ms/cm คลาด ระยะก็คลาด ดู [ระยะกับเวลา](/docs/code/distance-time)

**ทำไมค่าในโค้ดชมรมต่างจากในคู่มือผู้ผลิต?**
คู่มือผู้ผลิตให้ค่ากลางๆ ส่วนค่าในโค้ดชมรมวัดจากโดรนและพื้นสนามของเราเอง (เช่น 15.46 ms ต่อ ซม. ตอนไปข้างหน้า) ใช้ค่าในโค้ดเป็นหลัก และวัดซ้ำทุกครั้งที่เปลี่ยนแบตหรือเปลี่ยนพื้นที่

**โค้ดของชมรมใช้ภาษาอะไร?**
Arduino C++ บนบอร์ด Arduino ที่ติดกับโดรน ส่งคำสั่งให้ Flight Controller ผ่าน I2C

**กติกาแต่ละปีเปลี่ยน โค้ดต้องเขียนใหม่ทุกปีไหม?**
ส่วนใหญ่ไม่ ตัวคำสั่งบิน (`drone.fw`, `drone.sh` ฯลฯ) ใช้ต่อได้ ที่เปลี่ยนคือเส้นทางและกลไกในแต่ละภารกิจ กติกาในเว็บเก็บเป็นข้อมูลรายปีเพื่อแก้ได้ง่าย

## เรื่องฮาร์ดแวร์

**โดรนลอยแล้วไถลไปข้างเดียวตลอด**
calibrate ตอนโดรนไม่ราบ หรือพื้นสีดำล้วนทำให้ Optical flow อ่านผิด ทำใหม่บนพื้นเรียบมีลวดลาย

**เซอร์โวเปิดฝาไม่สุด / ปิดไม่สนิท**
ปรับค่า pulse ทีละ 25–50 ไมโครวินาที ดู [ปล่อยสัมภาระ](/docs/mechanisms/payload-drop) และ [Calibrate เซอร์โว](/docs/mechanisms/servo-calibration)

**แบตเตอรี่ใช้ได้กี่นาที?**
คู่มือผู้ผลิตระบุ 10 นาทีเมื่อลอยนิ่งไม่มีของแบก เมื่อแบกชุดปล่อยบอลและเคลื่อนที่บ่อยจะน้อยกว่านี้ ดู [แบตเตอรี่](/docs/physics/battery-power)

**สมัครสมาชิกเว็บเพื่ออะไร?**
สำหรับครูและสมาชิกที่ต้องการเพิ่มผลงาน ผู้อ่านทั่วไปไม่ต้องล็อกอิน
