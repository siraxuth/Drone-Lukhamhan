อ่านผ่านๆ ก่อนก็พอ เจอคำไหนไม่รู้ค่อยกลับมาเปิด

## การบินและฟิสิกส์

| คำ | ความหมาย |
| --- | --- |
| Throttle | ระดับกำลังรวมของมอเตอร์ ดันขึ้นคือขึ้น ลดลงคือลง |
| Roll | เอียงข้าง (ซ้าย/ขวา) รอบแกนหน้า–หลัง |
| Pitch | ก้มหรือเงยหัว รอบแกนซ้าย–ขวา |
| Yaw | หมุนหัวรอบแกนตั้ง ไม่เปลี่ยนความสูง |
| Thrust | แรงยกที่ใบพัดสร้าง |
| Hover | ลอยนิ่งอยู่กับที่ |
| CW / CCW | หมุนตามเข็ม / ทวนเข็ม (Clockwise / Counter-clockwise) |
| Motor mixing | ตัวผสมแรง: แปลงคำสั่ง "ไปหน้า" เป็นรอบของมอเตอร์ทั้ง 4 |
| PID | วิธีแก้ความคลาด: ดูความคลาดตอนนี้ (P) ที่สะสมมา (I) และที่กำลังเปลี่ยน (D) |
| IMU | ชุดเซ็นเซอร์ไจโรและมาตรความเร่ง บอกว่าเอียงและหมุนเท่าไร |
| LiDAR / ToF | ยิงแสงแล้ววัดเวลาสะท้อนกลับ ใช้วัดระยะถึงพื้น |
| Optical flow | กล้องดูลายพื้นเพื่อรู้ว่าโดรนไถลไปทางไหน |
| Dead reckoning | ประมาณตำแหน่งจากความเร็ว × เวลา โดยไม่มีเซ็นเซอร์ตำแหน่ง |
| Drift | การไถลหรือคลาดสะสมตามเวลา |

## ฮาร์ดแวร์

| คำ | ความหมาย |
| --- | --- |
| FC (Flight Controller) | สมองของโดรน อ่านเซ็นเซอร์และคุมมอเตอร์ |
| ESC | วงจรจ่ายกำลังให้มอเตอร์ตามสัญญาณ |
| LiPo / 3S | แบตเตอรี่ลิเธียมโพลิเมอร์ 3S = ต่ออนุกรม 3 เซลล์ ≈ 11.1 V |
| mAh | ความจุแบต 1,200 mAh = จ่ายกระแส 1.2 A ได้ราว 1 ชั่วโมง |
| KV | รอบต่อนาทีต่อโวลต์ของมอเตอร์ (เปล่า) |
| Servo | มอเตอร์ที่หมุนไปมุมที่สั่งได้ ใช้เปิดฝาปล่อยของและยิงลูกดอก |
| PWM | เปิด–ปิดสัญญาณเป็นจังหวะ เพื่อบอกค่า (เช่น มุมเซอร์โว) ด้วยความกว้างพัลส์ |
| I2C | สายสื่อสาร 2 เส้น (SDA, SCL) ที่ Arduino ใช้คุยกับ FC |
| GPIO | ขาที่ตั้งเป็นเข้าหรือออกก็ได้ |

## โค้ดและ Arduino

| คำ | ความหมาย |
| --- | --- |
| Sketch | โปรแกรม Arduino 1 โปรเจกต์ (ไฟล์ `.ino`) |
| `setup()` / `loop()` | ฟังก์ชันที่ Arduino เรียกเอง: ครั้งเดียวตอนเริ่ม / วนซ้ำตลอด |
| Pointer | ตัวแปรที่เก็บ "ที่อยู่" ของข้อมูล ไม่ใช่ตัวข้อมูลเอง |
| `->` | เรียกสมาชิกของ object ผ่าน pointer เช่น `pArduino->take_off()` |
| Class / Object | แบบพิมพ์ / ของจริงที่สร้างจากแบบพิมพ์ |
| `delay()` | หยุดรอตามมิลลิวินาที ระหว่างนั้นโค้ดอื่นไม่ทำงาน |
| `millis()` | เวลาที่นับจากเปิดบอร์ด ใช้จับเวลาโดยไม่หยุดรอ |
| Calibrate | ปรับเทียบ (ไจโรหรือค่าเวลาต่อระยะ) ให้ตรงกับของจริง |
| Magic number | ตัวเลขที่ฝังในโค้ดโดยไม่ตั้งชื่อ ควรย้ายไปเป็นค่าคงที่ใน `config.hpp` |

## การแข่งขัน

| คำ | ความหมาย |
| --- | --- |
| Payload | สัมภาระ (ลูกบอล) ที่โดรนบรรทุกไปปล่อย |
| Takeoff pad | แท่นที่โดรนขึ้น–ลง |
| T0 | เวลาแข่งสูงสุดต่อรอบ (ตามกติกาปี ๒๕๖๙ คือ 2 นาที 30 วินาที) |
| Poshold | โหมดล็อกตำแหน่ง โดรนใช้ Optical flow ไม่ให้ไถล |
