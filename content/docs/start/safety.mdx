โดรนที่หนัก 310 กรัมหมุนใบพัดหลายพันรอบต่อนาที เจ็บได้จริง และแบตเตอรี่ LiPo ไหม้ได้ถ้าใช้ผิด หน้านี้สั้นแต่ต้องอ่านครบ

## 1. ก่อนบินทุกครั้ง

**สภาพแวดล้อม**

- พื้นที่โล่ง ไม่มีสิ่งกีดขวาง เก็บของแตกง่ายและน้ำที่เปิดฝาออก
- ในอาคารบินต่ำกว่า 3 เมตร เพื่อลดความเสียหายถ้าตก
- ให้มองเห็นโดรนตลอด สัญญาณทะลุคน กระจก ผนังได้ไม่ดี
- พื้นต้องสว่าง เรียบ มีลวดลาย เลี่ยงสีดำล้วนและพื้นมันสะท้อนแสง
- ลมแรงหรือฝนตก งดบิน และห้ามบินเหนือน้ำ

**ตัวโดรน**

- ครอบกันใบพัดไม่แตกร้าว
- ใบพัดและมอเตอร์อยู่ตำแหน่งถูกต้อง (ตามเข็ม/ทวนเข็ม)
- เซ็นเซอร์ใต้ท้องไม่ถูกบัง
- แบตไม่บวม ไม่มีรอยแตก
- ไม่มีเศษวัสดุใต้ใบพัด ใบพัดหมุนได้อิสระ
- ชุดปล่อยลูกบอลและสายเซอร์โวไม่ไปติดใบพัด

**รีโมทและแบต**

- แบตโดรนและรีโมทไม่ต่ำ ถ้าไฟแดงให้ชาร์จก่อน แบตต่ำทำให้บินไม่เสถียร

## 2. กฎห้ามพลาด

1. **ห้ามบินเหนือคน** และห้ามบินพุ่งเข้าหาคนหรือผนัง
2. เก็บมือ นิ้ว ผม สายห้อยให้ห่างใบพัดเสมอ
3. โดรนตก **ให้ปิดเครื่องทันที** ไม่ต้องรอให้ใบพัดหยุดเอง เพราะมอเตอร์ที่ติดขัดจะร้อนและเสียหาย
4. นักบินหรือผู้ช่วยต้องมองเห็นโดรนตลอดเวลา
5. มีคนยืนอยู่ในสนามได้เฉพาะที่กติกากำหนด และห้ามเอามือเข้าใกล้โดรนที่ใบพัดยังหมุน

## 3. ซ้อมการปิดฉุกเฉิน

ก่อนลงแข่ง ซ้อมวิธี **ปิดมอเตอร์ฉุกเฉิน** ให้ทุกคนในทีมทำได้โดยไม่ต้องคิด ให้จับโดรน ( **บริเวณแบตเตอรี่** หรือ เอามือประคบบนล่างแล้วพลิก **แต่ต้องไว** ) แล้วพลิกทันทีหากพบว่าโดรนไม่บินตามโค้ดที่เขียนไว้ หรือ กดเปลี่ยนโหมดแล้วกดปุ่ม **tekeoff** บนรีโมท โดรนจะทำการ **auto_land** ลงให้**ทันที**

## 4. แบตเตอรี่ LiPo

- ใช้ที่ชาร์จที่ให้มา ชาร์จทีละก้อน มีคนดูตลอด
- แบตบวม ตก หรือมีรอยแตก **เลิกใช้** ห้ามชาร์จ
- เก็บในที่เย็น แห้ง ห่างของไวไฟ ไม่ทิ้งไว้ในรถที่ร้อน
- เสียบค้างกับโดรนตอนไม่ใช้นานๆ ไม่ได้ ถอดออก

## 5. ปัญหาหน้างานที่ควรตัดสินใจไว้ล่วงหน้า

| เหตุการณ์ | ทำอะไรทันที |
| --- | --- |
| โดรนเอียงไถลไปหาคน | จับโดรนแล้วพลิก หรือ (ผู้ช่วยหรือปุ่มรีโมท) |
| ไฟแดงกะพริบเร็ว (แบตต่ำ) | ปล่อยให้ลงจอดอัตโนมัติ ห้ามดึงขึ้นมาอีก |
| โดรนสั่นผิดปกติ | ลงจอดแล้วตรวจใบพัดและน็อตทุกตัว |
| ได้กลิ่นไหม้ ควัน | ปิดเครื่อง ถอดแบต วางไว้ในที่โล่งห่างของไวไฟ |
