พอร์ตสำคัญบนโมดูลควบคุมการบิน

| พอร์ต | ใช้ทำอะไร |
| --- | --- |

| ช่อง TF | ใส่ micro SD เก็บภาพและวิดีโอ |

| ปุ่ม | หน้าที่ |
| --- | --- |

| To&L | กดเพื่อขึ้นบิน (ลอยที่ราว 120 ซม.) กดอีกครั้งเพื่อลงจอด |
| Calibrate | กดเพื่อปรับเทียบโดรน (วางบนพื้นราบ) |
| Mode | กด = สลับโหมด coding / manual |
| ZL | เปลี่ยนความเร็วบิน ต่ำ/กลาง/สูง ดู LED3 |
| X Y A B และลูกศร | ปุ่มที่โปรแกรมกำหนดเองได้ (คือ KEY1–KEY14 ในโค้ด) |

ไฟ LED บนรีโมท

| LED | ความหมาย |
| --- | --- |
| LED1 | แดง = ยังไม่จับคู่ · เขียวกะพริบ = กำลังจับคู่ · เขียวค้าง = จับคู่แล้ว |
| LED2 | ดับ = manual · เขียว = coding |
| LED3 | ดับ = ช้า · เขียว = กลาง · แดง = เร็ว |
| LED4 | ดับ = Mode 1 · เขียว = Mode 2 |

## 6. ข้อสังเกตจากผู้ใช้จริง

- คู่มือบอกว่ากด To&L แล้วโดรนลอยที่ราว 120 ซม. แต่ในโค้ดของชมรมกำหนด `HEIGHT_TAKEOFF = 110` ไว้ ต่างกัน 10 ซม. เพราะโค้ดสั่งความสูงเองหลังขึ้นบิน ใช้ค่าในโค้ดเป็นหลักและวัดเองเสมอ
- เวลาบิน 10 นาทีเป็นตอนลอยนิ่งไม่มีของแบก ภารกิจจริงที่มีชุดปล่อยบอลและเคลื่อนที่บ่อยจะน้อยกว่านั้น อ่านเหตุผลที่ [แบตเตอรี่](/docs/physics/battery-power)
- ผิวสีดำล้วนหรือผิวมันสะท้อนแสงทำให้ Optical flow อ่านพลาด โดรนจะไถล สนามแข่งใช้พื้นที่มีลวดลายเพราะเหตุนี้
