เรียงตามอาการที่เห็น หาข้อที่ตรงแล้วทำตามสาเหตุ ถ้าลองแล้วไม่หาย ให้แนบภาพหน้าจอทั้ง Blender (รวมแผง Outliner และ Properties) แล้วถามพี่ในชมรม

## ปัญหาการติดตั้งและหน้าจอ

| อาการ | สาเหตุที่เป็นไปได้ | วิธีแก้ |
| --- | --- | --- |
| ไม่เห็นแถบ RCSA | ยังไม่ได้เปิด add-on หรือเมาส์ไม่ได้อยู่ใน Viewport ตอนกด N | ติ๊กเปิด add-on ใน Preferences แล้วกด N ในขณะที่เมาส์อยู่กลาง Viewport ตามบท [ติดตั้ง add-on](/docs/lettering/rcsa-addon) |
| ติดตั้ง add-on แล้วแจ้ง error | ใช้ Blender คนละรุ่น หรือแตกไฟล์ zip ก่อน | ใช้ 4.5.x LTS และเลือกไฟล์ .zip ตัวเดิมโดยไม่แตก |
| เปิดโปรเจกต์ใหม่แล้วไม่มี Collection | ยังไม่ได้ Save Startup File | ทำตามบท [ตั้งค่าเริ่มต้น](/docs/lettering/startup-collections) |
| กด Numpad แล้วไม่เปลี่ยนมุม | แล็ปท็อปไม่มี Numpad | เปิด Emulate Numpad ใน Preferences → Input |
| หมุนมุมมองไม่ได้ | แทร็กแพดไม่มีปุ่มกลาง | เปิด Emulate 3 Button Mouse แล้วใช้ Alt + คลิกซ้าย |

## ปัญหาสีและการตั้งค่า

| อาการ | สาเหตุที่เป็นไปได้ | วิธีแก้ |
| --- | --- | --- |
| สีโดรนซีด ไม่สด | View Transform ไม่ใช่ Standard | Render → Color Management → View Transform = Standard |
| เปลี่ยนสีโดรนลำเดียว ลำอื่นเปลี่ยนตาม | ใช้ Material เดียวกันทั้งกลุ่ม | ลบ Material เดิม แล้วกด New Material (ALL) ตามด้วย (EACH) |
| โดรนเป็นสีดำ ไม่เรืองแสง | Material ไม่ใช่ Emission หรือ Strength เป็น 0 | ในแท็บ Material ตั้ง Surface เป็น Emission และ Strength เป็น 1 |
| โดรนขึ้นสีเหลือง | เคลื่อนที่เร็วกว่าที่กำหนด | ย้ายตำแหน่งให้ใกล้กันขึ้น หรือเว้นเฟรมให้ห่างกันขึ้น |
| ไทม์ไลน์สั้นหรือยาวเกิน เวลาไม่ตรง | FPS ไม่ใช่ 10 | Output → Frame Rate → Custom → 10 |

## ปัญหาตอนวางโดรน

| อาการ | สาเหตุที่เป็นไปได้ | วิธีแก้ |
| --- | --- | --- |
| ลากกรอบเลือกแล้วภาพต้นแบบติดไปด้วย | Pictures ยังเลือกได้ | ปิด Selectable ของคอเล็กชั่น Pictures |
| โดรนหลุดไปอยู่ผิดกลุ่ม | เพิ่มวัตถุตอนที่เลือกคอเล็กชั่นผิด | เลือกวัตถุ กด M แล้วเลือกคอเล็กชั่นที่ถูก |
| ตัวอักษรอ่านกลับด้าน | ดูจากด้านหลังของภาพ | เปลี่ยนมุมเป็นอีกด้านด้วย Ctrl + Numpad 1 แล้วดูว่าอ่านถูกทางหรือไม่ |
| Min distance น้อยเกิน | โดรนอยู่ใกล้กันเกินไป | ขยายภาพ (ปุ่ม S) หรือใช้โดรนน้อยลง แล้ววางใหม่ |
| ย้ายผิดแล้วงงว่าอยู่ตรงไหน | ใช้ G หลายครั้งโดยไม่ดูแกน | Ctrl + Z ย้อนกลับ หรือ Alt + G เพื่อให้ตำแหน่งกลับศูนย์ |

## เช็กลิสต์ก่อนส่งงาน

ไล่ทีละข้อก่อนกดส่งทุกครั้ง

1. **เวอร์ชัน**: ใช้ Blender 4.5.x LTS และ add-on ของโดรนแปรอักษรเปิดอยู่
2. **Collection**: มี Drones, Empty, Pictures ครบ
3. **FPS**: 10
4. **สี**: View Transform เป็น Standard และโดรนทุกลำใช้ Emission แยก Material รายลำ
5. **Safety Check**: ระยะห่าง ความสูง และความเร็วผ่านทั้งหมด ไม่มีโดรนสีเหลือง
6. **มุมหน้า**: ดูใน Front Orthographic แล้วภาพอ่านถูกด้าน
7. **ไฟล์**: บันทึกชื่อที่สื่อความหมาย มีสำเนาสำรอง เปิดใหม่แล้วเล่นได้
8. **กติกา**: เทียบจำนวนโดรน ความสูง และเวลากับกติกาของรายการที่แข่งปีนั้น

<Callout type="info" title="เรื่องการส่งออก (export)">
แผง RCSA มีส่วน Export สำหรับส่งออกไฟล์ที่ใช้ในการแข่งขัน สไลด์ของโรงเรียนยังไม่ได้อธิบายขั้นตอนนี้ ให้ตรวจรูปแบบไฟล์และวิธีส่งกับกติกาของรายการ หรือถามพี่ที่ดูแลงานแปรอักษรของชมรมโดยตรงก่อนส่ง
</Callout>

## ฝึกต่อ

1. ทำหัวใจให้เปลี่ยนสีไล่จากกลางไปขอบ
2. ทำตัวอักษรชื่อโรงเรียนด้วยโดรนไม่เกิน 100 ลำ ให้ผ่าน Safety Check
3. ลองเคลื่อนโดรนทั้งกลุ่มเข้าหากล้อง (ผูกกับ Empty) ให้หัวใจเต้นแบบย่อขยาย แล้วดูว่าความเร็วเกินหรือไม่
