โปรเจกต์โดรนแปรอักษรทุกงานต้องมีโครงเดียวกัน ถ้าต้องสร้างโฟลเดอร์ซ้ำทุกครั้งก็เสียเวลา บทนี้ทำโครงไว้ครั้งเดียว แล้วสั่งให้ Blender จำเป็นค่าเริ่มต้น

## 1. สร้าง Collection

Collection คือโฟลเดอร์ใน Outliner (ขวาบน) ไว้เก็บของเป็นกลุ่ม งานนี้ต้องมี 3 กลุ่ม

| ชื่อ | เก็บอะไร |
| --- | --- |
| Drones | ทรงกลมที่แทนโดรนทุกลำ |
| Empty | กล่องล่องหน (Empty) ที่ใช้ขยับโดรนหลายลำพร้อมกันเวลาทำภาพเคลื่อนไหว |
| Pictures | ภาพต้นแบบและ asset อื่นที่ใช้ช่วยวางตำแหน่ง |

<Steps>
<Step>

เอาเมาส์ไปที่ Outliner (ขวาบน) คลิกขวาที่พื้นที่ว่าง เลือก **New Collection**

</Step>
<Step>

กด **F2** เพื่อตั้งชื่อ พิมพ์ `Drones` แล้วกด Enter

</Step>
<Step>

ทำซ้ำอีก 2 รอบ ตั้งชื่อ `Empty` และ `Pictures`

</Step>
</Steps>

<Callout type="info" title="สะกดให้เป๊ะ">
ใช้ตัวพิมพ์ใหญ่ตัวแรกตามนี้ทุกครั้ง ทีมที่ใช้ชื่อเดียวกันจะแลกไฟล์และช่วยกันตรวจได้ง่าย และถ้า add-on มีส่วนที่อ้างชื่อ Collection จะได้ไม่หาไม่เจอ
</Callout>

## 2. บันทึกเป็นค่าเริ่มต้น

ตอนนี้โครงอยู่เฉพาะในไฟล์ที่เปิดอยู่ ถ้าเปิดโปรเจกต์ใหม่จะหายหมด ต้องบอก Blender ให้จำไว้

<Steps>
<Step>

กดเมนู **File** ที่มุมซ้ายบน

</Step>
<Step>

เลือก **Defaults → Save Startup File**

</Step>
<Step>

ทดสอบ: ปิด Blender แล้วเปิดใหม่ เลือก **New → General** ถ้าเห็นคอเล็กชั่น Drones, Empty และ Pictures อยู่ครบเหมือนเดิม แปลว่าบันทึกสำเร็จ

</Step>
</Steps>

## เก็บให้เป็นระเบียบตั้งแต่ตอนนี้

ก่อนกด Save Startup File อาจลบของที่ไม่ใช้ในฉากเริ่มต้นออกด้วย เช่น ลูกบาศก์ ถ้ารอบหน้ายังเห็นของเก่าโผล่มา ให้ลบแล้วบันทึกซ้ำ การบันทึกซ้ำจะเขียนทับค่าเดิมทุกครั้ง

<Callout type="warn" title="ค่านี้เป็นของเครื่องนั้น">
Startup File เก็บในเครื่องของคุณ ไม่ได้ติดไปกับไฟล์งาน ถ้าไปใช้คอมที่โรงเรียนต้องทำขั้นตอนนี้ใหม่ในเครื่องนั้น หรือเปิดไฟล์ .blend ที่เคยบันทึกไว้แล้วใช้ต่อ
</Callout>
