ภาพโดรนที่สวยไม่ได้มีแค่สีเดียว การไล่สีคือการให้โดรนเรียงกันเปลี่ยนจากสีหนึ่งไปอีกสีอย่างลื่น เช่นจากน้ำเงินไปม่วง บทนี้ฝึกกับโดรนเจ็ดลำเรียงแถวเพราะดูผลง่ายที่สุด คลิปยาวราว 5 นาที เป็นการสาธิตครบ

<LessonVideo name="gradient" caption="ไล่สีโดรนเจ็ดลำด้วยแผง LED Control: สีหลัก สีรอง และ Fade" />

## เตรียมโดรนเจ็ดลำ

<Steps>
<Step>

เพิ่มทรงกลม 1 ลำใน Collection **Drones** แล้วใช้ **Shift + D** ทำสำเนาจนมีเจ็ดลำเรียงเป็นแถวในแนวนอน (ใช้ G → X ตามด้วยตัวเลขให้ห่างเท่ากัน)

</Step>
<Step>

เลือกทั้งหมดด้วยปุ่ม **A** แล้วกด **New Material (ALL)** ตามด้วย **New Material (EACH)** ในแถบ RCSA ตามบท [พื้นผิว สี และ FPS](/docs/lettering/material-color-fps)

</Step>
</Steps>

## แผง LED Control

ในแถบ RCSA ของแผง N มีหัวข้อ **LED Control** ที่มีช่องเลือกสีสองช่อง

| ส่วน | ใช้ทำอะไร |
| --- | --- |
| Primary (สีหลัก) | สีตั้งต้น ลำแรกของกลุ่มที่เลือก |
| Secondary (สีรอง) | สีปลายทาง ลำสุดท้ายของกลุ่มที่เลือก |
| Apply | ใส่สีนั้นให้โดรนที่เลือก |
| Fade to | ไล่ระดับจากสีหนึ่งไปอีกสี ข้ามโดรนที่เลือก |

<LessonImage name="spheres-scene" caption="แผง LED Control ในแถบ RCSA พร้อมโดรนเจ็ดลำที่เรียงเป็นแถวในฉาก" />

## ขั้นตอนไล่สี

<Steps>
<Step>

เลือกโดรนทั้งเจ็ดลำ (กด A หรือลากกรอบ)

</Step>
<Step>

กดช่อง **Primary** เลือกสีแรก เช่น น้ำเงิน

</Step>
<Step>

กดช่อง **Secondary** เลือกสีที่สอง เช่น ม่วง

</Step>
<Step>

กดปุ่มไล่สี (Fade to) ในส่วน LED Control โดรนทั้งเจ็ดจะเปลี่ยนสีไล่จากน้ำเงินค่อยๆ ไปม่วง

</Step>
<Step>

ลองสลับสีหลักและสีรองแล้วทำอีกครั้ง เพื่อดูทิศของการไล่สีกลับด้าน

</Step>
</Steps>

<Callout type="info" title="ทิศของการไล่สีขึ้นกับลำดับของโดรน">
โปรแกรมไล่สีตามลำดับที่เลือก ไม่ใช่ตามตำแหน่งในจอ ถ้าสีออกมาสลับจุดแปลกๆ ให้ดูลำดับชื่อของโดรนใน Outliner ใช้ Rename ตั้งชื่อเรียงให้ตรงกับที่ต้องการ แล้วลองใหม่
</Callout>

## เลือกคู่สีให้ดูดี

| คู่สี | ผลที่เห็นบนท้องฟ้ามืด |
| --- | --- |
| น้ำเงิน → ม่วง | ไล่ต่อเนื่อง ตาสบาย |
| เขียว → เหลือง | สดใส ใกล้กันตามวงล้อสี |
| แดง → ชมพู | อบอุ่น |
| แดง → เขียว | ช่วงกลางจะขุ่น ถ้าไล่ตรงจะผ่านสีน้ำตาลหรือเทา |
| ขาว → สีเข้ม | ขาวสว่างกว่าสีอื่นมาก ตาจะมองเห็นขาวก่อน |

ท้องฟ้ายามค่ำทำให้ LED ดูสว่างกว่าในจอ สีที่ซีดหรือใกล้กันมาก (เช่นฟ้าอ่อนกับขาว) แยกยากบนฟ้าจริง เลือกคู่สีที่ต่างกันชัดเจน

## ลองเอง

1. ไล่สีโดรนเจ็ดลำจากแดงไปน้ำเงิน แล้วบันทึกไฟล์ (Ctrl + S)
2. เปลี่ยนเป็นโดรน 14 ลำ (เลือกทั้งแถว กด Shift + D แล้ววางเป็นแถวที่สอง) แล้วลองไล่สีแนวตั้ง
3. ลองไล่สีสามสี โดยไล่สองรอบ: ครั้งแรกกับสี A → B ครั้งที่สองกับ B → C ในช่วงที่ต่อกัน
