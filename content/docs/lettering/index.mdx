---
title: โดรนแปรอักษรคืออะไร
description: ออกแบบการแสดงโดรนแปรอักษรด้วย Blender 4.5 LTS ตั้งแต่ติดตั้งโปรแกรมจนวางโดรน ลงสี และตรวจความปลอดภัยก่อนส่งงาน
---

โดรนแปรอักษรคือโดรนหลายสิบถึงหลายร้อยลำที่บินขึ้นฟ้าพร้อมกัน แต่ละลำเป็นหนึ่งจุดแสง พอรวมกันก็เป็นตัวอักษร รูปหัวใจ หรือลายสิงโตตามที่ออกแบบไว้ งานแข่งประเภทนี้ไม่ได้ให้เขียนโค้ดสั่งบินทีละลำ แต่ให้ **ออกแบบฉากในโปรแกรม Blender** ว่าแต่ละลำอยู่ตรงไหน เปลี่ยนสีเมื่อไร เคลื่อนที่ไปไหน แล้วส่งไฟล์เข้าระบบเพื่อแปลงให้โดรนจริงรู้รูปร่างการบิน และสามารถขึ้นสู่ท้องฟ้าได้

<LessonImage name="demo-result" caption="ตัวอย่างงานที่ออกแบบใน Blender: ลายสิงโตกับข้อความ 2569 ประกอบจากจุดโดรนเป็นร้อยจุด มุมมองเป็น Front Orthographic" />

คู่มือชุดนี้ดัดแปลงจากสไลด์ "คู่มือการออกแบบโดรนแปรอักษร ฉบับโรงเรียนลือคำหาญวารินชำราบ" เก็บขั้นตอนและคลิปตามต้นฉบับ แล้วเติมคำอธิบายว่าแต่ละปุ่มทำอะไร ทำไมต้องตั้งค่านั้น และพังตรงไหนบ่อย

## ต้องมีอะไรบ้าง

| ของที่ต้องมี | ใช้ทำอะไร |
| --- | --- |
| คอมพิวเตอร์ที่ลง Blender ได้ (Windows, macOS หรือ Linux) | ออกแบบฉาก |
| เมาส์ 3 ปุ่ม หรือแทร็กแพดที่ตั้งค่าตามบท [มุมมองและการเคลื่อนกล้อง](/docs/lettering/viewport) | หมุนและเลื่อนมุมมอง |
| Blender **4.5.x LTS** | โปรแกรมออกแบบ ใช้รุ่นอื่นไม่ได้ |
| add-on ของโดรนแปรอักษร (ไฟล์ .zip) | ปุ่มช่วยสร้างโดรน ลงสี และตรวจความปลอดภัย |
| ภาพต้นแบบ เช่น ตัวอักษรหรือโลโก้ | ใช้วางตำแหน่งโดรน |

## คำที่จะเจอบ่อย

| คำ | ความหมายในงานนี้ |
| --- | --- |
| Collection (คอเล็กชั่น) | โฟลเดอร์ใน Blender ไว้จัดกลุ่มของ เช่น กลุ่มโดรน กลุ่มภาพต้นแบบ |
| Object | ของหนึ่งชิ้นในฉาก เช่น ทรงกลม 1 ลูก = โดรน 1 ลำ |
| UV Sphere | ทรงกลมที่ใช้แทนโดรน |
| Empty | วัตถุล่องหน ไม่มีรูปร่าง ใช้เป็นตัวจับกลุ่มหรือตัวขยับโดรนหลายลำพร้อมกัน |
| Material (พื้นผิว) | ตัวกำหนดสีและการเรืองแสงของวัตถุ โดรนแต่ละลำมีสีของตัวเอง |
| Keyframe (คีย์เฟรม) | จุดที่ปักไว้บนไทม์ไลน์ว่าเฟรมนี้ตำแหน่งหรือสีเป็นอย่างไร Blender คำนวณช่วงระหว่างให้เอง |
| Viewport | หน้าต่างกลางจอที่เห็นฉาก 3 มิติ |
| FPS | จำนวนเฟรมต่อวินาที งานแข่งใช้ 10 |

<Callout type="info" title="เรื่องภาษาของ Blender">
ชื่อเมนูในคู่มือนี้เป็นภาษาอังกฤษตามที่สไลด์และคลิปใช้ ถ้าคุณเปลี่ยน Blender เป็นภาษาไทยหรือภาษาอื่น ชื่อเมนูจะต่างไป แต่คีย์ลัดเหมือนเดิม แนะนำให้ใช้ภาษาอังกฤษไว้ก่อนเพื่อให้ตามคลิปทัน
</Callout>
